# NetShield AI

## Intelligent Intrusion Detection System

NetShield AI is a real-time Intrusion Detection System (IDS) developed using Python, Scapy, Flask, SQLite, and Machine Learning.

## Features

- Real-Time Packet Capture
- Port Scan Detection
- Brute Force Detection
- Anomaly Detection
- Alert Management System
- Flask Dashboard
- SQLite Database Storage
- AI-Based Attack Classification

## Technologies

- Python
- Scapy
- Flask
- SQLite
- SQLAlchemy
- Pandas
- NumPy
- Scikit-Learn
- HTML/CSS/JavaScript

## Machine Learning

The project includes a Random Forest based attack classification model trained on intrusion detection datasets.

Attack Classes:

- Benign
- FTP-BruteForce
- SQL Injection
- Bot
- DDoS Attack
- DoS Attack
- Brute Force Web
- Brute Force XSS
